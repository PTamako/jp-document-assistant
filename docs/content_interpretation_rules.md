# 扩展解读范围：日文使用说明、政策法规与活动说明

本软件**不仅识别收支，也解读非财务日文内容**。原始文本或图像经用户选择导入，抽出可追溯的关键段落，用户确认后可单向输出 HomeFlow 待办与知学单词/句子卡片；只有明确、已经实际发生的收支才允许创建家計簿候选。

| 类型 | 建议 `category` | 提取信息 | 与其他 App 联动 |
|---|---|---|---|
| 取扱説明書／使用说明 | `manual` | 产品名称/型号、使用步骤、禁忌、警告、故障处理、保养周期、保修/官方出处 | HomeFlow 保养任务；知学技术词句；无实际支出则不记账 |
| 法律、行政通知、在留/税务/社保政策 | `policy` / `regulation` | 发布机构、施行/公布/修订日期、适用人群、条件、材料、办理渠道、费用、申报/过渡期限、文号/版次 | HomeFlow 申请/提交提醒；知学行政日语；真实费用由用户确认后记账 |
| 活动、优惠、积分、抽奖 | `campaign` | 主办方、资格、报名期限、使用期间、优惠上限、适用/排除商品、是否可併用、积分结算、取消限制 | HomeFlow 参加/使用截止提醒；知学生活日语；仅实际消费/返现写家計簿 |
| 服务条款与合同 | `terms` | 合同双方、有效期、自动续约、费用、违约金、通知/解约期限、要确认的限制 | HomeFlow 合同续约/解约提醒；知学敬语词句；已付费用经确认记账 |

**关键措辞**：対象外（不适用）、併用不可（不可与其他优惠叠加）、上限に達し次第終了（名额/额度满时终止）、必着（截止日必须送达）、消印有効（邮戳有效）、申請が必要（需主动申请）、自動更新（自动续约）、別途料金（另外收费）、原則として（原则上）、例外（例外）。必须提供来源句、中文解释和用户可能采取的动作，不能只给抽象摘要。

**政策法规可信度**：每次展示要明确区分 `source_document_date`（文件发布时间/版本）和 `official_current_verified_at`（系统最后通过官方来源确认现行有效的时间，可为 `null`）。若尚未实时查证，显示“仅解释上传版本，未核实当前有效性”，不能从上传的旧法规推断最新规定。若能用户主动打开官方链接，仅以可信机构官网为准。内容是解释和办事辅助，不替代律师、税理士、行政书士、医生或主管部门的专业判断；风险大的期限、办理资格、法律后果都提示人工核实。

**准确性**：任何识别出的金额、资格条件、日子与例外条款须可点开原始证据。日文“一般规定”和用户自身情况分开展示，不自动断言用户符合活动资格、补贴或退税资格。OCR 无法识别小字/脚注时标明“可能有未识别的重要限制”。

**隐私和节流**：已有可复制的文字/Google Docs 优先直接解析，不耗图像 OCR；一份文书只做一次模型解释，学习候选复用；原件仅用户要求才保留 R2；默认私人，别人的政策文件/办公手册不得未经授权向其他系统完整复制。
