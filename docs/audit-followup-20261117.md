# 文书助手定向审查整改（2026-11-17）

本记录覆盖此前《全面审查》后用户要求的**非 OCR、非 Google 导入验证、非双人 iPhone 验收**整改。后续历史章节中「未部署」「全部联动都需要管理员审批」是历史快照，不是当前生产结论。

## 代码与授权边界

- 已修复候选同步页的注释吞掉表单初始化：切换文书、词句或任务候选时明确清理上个任务负责人、额外积分、隐私确认和家庭分享确认；不可用之前的勾选替代新的人工确认。已有不确定联动的幂等重试仍只恢复相同候选的冻结草稿。
- HomeFlow 私人任务及知学生词/句子属于本人，统一身份验证后直接提交，不送管理员审批。家庭账本真实收入/支出明细由普通成员请求管理员审查；管理员已有权限保持不变。
- 普通成员 SBI/个人资产转移不进入家庭收入／支出审批，也不会被伪装为现金收支。原桥接只能处理遗留账本记录，而非已独立确认的本人资产操作：**11月17日后续 PR #106 已实现并部署专用个人 SBI 转移执行器**：由 HomeFlow 成员本人确认真实金额及生效日，调用家計簿私有 Worker，以签名和幂等回执存储个人资产转移记录。不计收支、不产生基金份额，也不推断证券实际成交。当前并不自动更新 SBI 证券余额；用户资产余额必须由已有记账本官方记录或本人确认的数据支持。
- 家庭明细的成员审批必须由 Kakeibo 私有 Worker 对成员稳定现金账户提供 HMAC 验证，不允许以昵称/展示名代替账户 ID。本次为现有私有 Worker 添加 read-only 的 document-accounts/list,verify 路由，启用需两端同一独立私钥以及已有生产 Service Binding。生产接入先后要先部署 Kakeibo Worker 再发布文书助手，缺失依旧 fail-closed。
- 不调整既有文书所有权、R2、Google、OCR、D1 数据。私人只本人可读写，分享给家人后接收者仅可读，由原分享人删除/修改。

## 不属于这次验收的项目

用户明确排除 OCR/Google 导入验证、双人 iPhone 验收；无真实财务或个人文书写入测试。代码自动化通过不等同真机或者全功能真实业务验收。

## 2026-11-17 后续：默认现金和日文分类（本次 PR）

- 家計簿独立稳定金融账户表可以暂时为空；经 HomeFlow 核验的成员可从记账本正式 `payment_sources` 读取真实 `現金`，并通过本人/家庭确定性 ID 选择，列表只读。用户确认家庭明细审批时，目标端仅登记内部零余额现金会计身份用于签名与外键校验；不创建银行卡、支付方式、现金收入或支出。
- 文书助手成员分类由家計簿 `category_source` 返回正式日文显示名及内部分类值，不再允许自由文本猜测。在 HomeFlow 家庭明细审批完成前不生成正式账本记录。
- 共享信用卡及其他余额类金融资产仍有独立账务和卡片利用额规则，**不得擅自将其视为现金而改记账**；需专用受审核执行器，尚未完成本轮扩展。
- OCR、Google 实际导入与双 iPhone 真机测试仍未在本次代码变更中冒称通过。
